# IJDRR RULES CHECKLIST

Extracted from the IJDRR Guide for Authors (Elsevier, July 2026 version).
Verify each item before submission. Item numbers reference the source.

---

## Manuscript format

- [ ] Main file is .doc, .docx, or LaTeX .tex. PDF NOT accepted as source.
- [ ] Word documents: single-column layout (not two-column).
- [ ] LaTeX: use elsarticle.cls, standard packages only.
- [ ] Abstract <= 250 words, single paragraph, unstructured.
- [ ] Keywords: 1-7 English, no "and" or "of".
- [ ] Highlights file: 3-5 bullets, each <= 85 characters including spaces.
- [ ] Section numbering: 1, 1.1, 1.1.1, 1.2 (no "Section 1", just "1").
- [ ] Cross-references cite by number ("see Section 3.2", "Fig. 4a").

## Language

- [ ] Consistent US or UK English (not mixed).
- [ ] AI use disclosed if applicable (in Acknowledgements or Methods,
      per Elsevier policy Jan 2023 update).
- [ ] AI cannot be an author.

## Figures

Vector line drawings (line-only plots):
- [ ] Format EPS or PDF, fonts embedded (Type 42 in matplotlib).

Halftones (photos, raster maps):
- [ ] TIFF, JPG, or PNG.
- [ ] Minimum 300 dpi.
- [ ] Minimum 1063 px width at single column (3.54 in).
- [ ] Minimum 2244 px width at full page (7.48 in).

Bitmapped line drawings:
- [ ] TIFF, JPG, or PNG.
- [ ] Minimum 1000 dpi.
- [ ] Minimum 3543 px width at single column.
- [ ] Minimum 7480 px width at full page.

Combinations (line + halftone):
- [ ] TIFF, JPG, or PNG.
- [ ] Minimum 500 dpi.
- [ ] Minimum 1772 px width at single column.
- [ ] Minimum 3740 px width at full page.

All figures:
- [ ] One figure per file.
- [ ] Filename: Figure_1, Figure_2, ... (underscore, no space, no
      extension in the manuscript reference).
- [ ] Legend/caption below the figure in the manuscript.
- [ ] Colour figures print at no extra charge for online-only pdfs.

Maps:
- [ ] Show only the study area, not the entire country/continent
      surrounding it.
- [ ] Caption must include: "Map lines delineate study areas and do not
      necessarily depict accepted national boundaries."
- [ ] Scale bar and north arrow present.
- [ ] Coordinate grid or clear coordinates on axes.

Graphical abstract:
- [ ] Format TIFF, EPS, PDF, or MS Office.
- [ ] Minimum 531 x 1328 px (h x w).
- [ ] Readable at 5 x 13 cm printed size.
- [ ] No text-only slides.

## Tables

- [ ] Editable text (not embedded images).
- [ ] Placed in the text near first citation, or all at the end - be
      consistent.
- [ ] No vertical rules.
- [ ] No cell shading.
- [ ] Each table numbered consecutively (Table 1, Table 2, ...).
- [ ] Descriptive title above each table.

## Equations

- [ ] Editable text (Word equation editor or MathType).
- [ ] Variables italic; functions like exp, log upright.
- [ ] Fractions as solidus /x rather than stacked where inline.
- [ ] Numbered right-justified in parentheses if referenced in text.

## References

- [ ] Numbered in square brackets [1], [2] ... in order of first
      appearance.
- [ ] Multiple citations: [3,6,8] or [3-8].
- [ ] Journal names abbreviated per LTWA
      (https://portal.issn.org/ltwa).
- [ ] Dataset references prefixed with [dataset].
- [ ] All DOIs included where available.
- [ ] Bibliography style: Elsevier numbered.

## Author information

- [ ] All authors' full names, affiliations, ORCID iDs.
- [ ] One corresponding author with email.
- [ ] CRediT contributor statement covering:
  Conceptualization, Methodology, Software, Validation, Formal
  Analysis, Investigation, Resources, Data Curation, Writing - Original
  Draft, Writing - Review & Editing, Visualization, Supervision, Project
  Administration, Funding Acquisition.
- [ ] Declaration of competing interest (even if "none").

## Data and code

- [ ] Data availability statement present.
- [ ] Research Data Option C: deposit is MANDATORY. Use Zenodo, Mendeley
      Data, or Figshare and include the DOI.
- [ ] Code availability statement (GitHub link OK, cite specific
      release tag).

## Peer review

- [ ] Single-blind (author names visible to reviewers).
- [ ] Minimum 2 reviewers.
- [ ] Suggested reviewers: 3-5 names, valid emails, no conflict.
- [ ] Opposed reviewers optional (with justification).

## Post-submission - things NOT allowed

- [ ] No adding, removing, or reordering authors after acceptance
      (allowed during review with editor approval and all authors'
      consent, but avoid).
- [ ] No PDF-only source file.
- [ ] No double-column Word.
- [ ] No embedded images of tables or equations.
- [ ] No AI listed as an author.
- [ ] No mixed US/UK English.
- [ ] No submissions currently under review elsewhere.
- [ ] No prior publication (arXiv preprint OK, cite it).
- [ ] No copyrighted material (photos, tables from other papers) without
      permission letter.
- [ ] No boundary lines on maps that could be politically controversial
      (use the required caption note).
- [ ] No sensitive personal data in supplementary.
- [ ] No supplementary videos larger than 150 MB.

---

## Post-acceptance

- [ ] Corresponding author signs Elsevier's Journal Publishing Agreement.
- [ ] Choose CC-BY licence (default for Gold OA).
- [ ] APC handling: check waiver applied automatically. If not, contact
      editorial office before proof stage.
- [ ] Proof corrections within 48 hours of receipt.
- [ ] Update Zenodo deposit with the final published DOI cross-reference.
